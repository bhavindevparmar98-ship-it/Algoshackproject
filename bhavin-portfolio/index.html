Process

How a build usually runs.

  1. Read the brief

    Go through the Figma file, client requirements or reference website and list the pages and components.

  2. Set up the structure

    Create the theme or Webflow project, global styles, reusable components and CMS fields.

  3. Build and make responsive

    Build each page and check it at phone, tablet and desktop widths.

  4. Review and hand over

    Compare the result with the design, fix differences and leave the content easy to edit.
